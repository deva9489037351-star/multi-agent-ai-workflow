# multi-agent-ai-workflow
# 🧠 Executive AI Council – Multi-Agent Decision Making System

A multi-agent AI workflow built using **n8n** and **Groq LLMs** that simulates an executive board meeting for decision-making.

Instead of relying on a single AI response, this workflow assigns specialized AI agents to analyze a problem from different perspectives before producing a final executive recommendation.

---

## 🚀 Project Overview

Traditional LLMs generate a single response by considering everything at once.

This project demonstrates an **Agentic AI** approach where multiple AI agents collaborate to solve the same problem.

Each agent has a unique responsibility:

- 👨‍💻 Chief Technology Officer (CTO)
- 💰 Chief Financial Officer (CFO)
- ⚠️ Chief Risk Officer (CRO)
- 📚 Chief Learning Officer (CLO)
- 📈 Chief Strategy Officer (CSO)
- 😈 Devil's Advocate
- 👨‍⚖️ Council Chair

The Council Chair reviews every expert's opinion and produces one final decision.
